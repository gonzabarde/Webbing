PRODUCTION OPERATING SYSTEM — v1
================================

OBJETIVO GENERAL
----------------
Convertir el sistema de módulos (Discovery, Positioning, Brand Translation, Visual Language, Concept Generation, Perception, Visual Direction, Innovation, Process) en un flujo de producción real, repetible y validable.

Este documento no reemplaza los módulos.
Los orquesta.

Su función es:
1. Decidir qué módulo ejecutar.
2. Validar la salida de cada fase.
3. Determinar si se puede avanzar.
4. Bloquear retrabajo innecesario.
5. Registrar decisiones.
6. Mantener coherencia entre estrategia, concepto, percepción, dirección visual, diseño y build.

PRINCIPIOS DEL SISTEMA
----------------------
1. Toda decisión debe ser explicable.
2. Cada fase debe producir un entregable claro.
3. No se avanza si el gate falla.
4. Claude propone; el humano valida lo estratégico.
5. El diseño no empieza antes de validar estrategia, concepto y dirección visual.
6. Si una decisión no cambia percepción, comportamiento o diseño, no vale.
7. La originalidad solo importa si sigue siendo defendible.
8. La marca debe ser reconocible aun sin logo.
9. La innovación debe reforzar claridad, no competir con ella.
10. El proceso debe dejar trazabilidad.

-----------------
CLAUDE:
- Analista

ESTÁNDARES DE VALIDACIÓN
------------------------
Cada fase debe cerrar con:
- Objective Check
- Deliverable Check
- Gate Check
- Failure Check
- Next Step

Cada gate tiene tres posibles estados:
- PASS
- REVISE
- FAIL

PASS:
Se avanza.

REVISE:
Se corrige en la misma fase y se vuelve a evaluar.

FAIL:
Se vuelve a la fase anterior o se detiene el proceso.

FASE 0 — BRIEF INTAKE
------------------------------------------------------------

--------
Entender el encargo inicial y detectar si faltan datos críticos.

INPUTS
------
- Solicitud del cliente
- Objetivo general
- Contexto inicial
- Expectativas
- Restricciones conocidas

PROCESO

2. Clasificar el tipo de proyecto.

PASS:

------
¿El negocio, la audiencia, la categoría y la competencia están suficientemente entendidos?

REVISE:

- No hay competidores reales.
- No se detectaron patrones.
- No hay oportunidad clara.
- El nivel de confianza no está claro.
